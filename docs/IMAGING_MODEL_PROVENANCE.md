## 3. Reproducible Two-Mode Training & Calibration Pipeline (`ai-service-python/imaging_pipeline/`)

`ai-service-python/imaging_pipeline/train_densenet.py` implements a unified, deterministic PyTorch `DenseNet-121` (`densenet121(weights=None)` with `nn.Linear(1024, 4)` head) training and export workflow supporting two modes:

### 3.1 Mode A: Authorized External Radiology Cohort (`--manifest-csv`)
For institutions or investigators who hold legitimate local access to NIH ChestX-ray14, CheXpert, MIMIC-CXR, RSNA Pneumonia, or local IRB-approved 2D MRI slices:
1. Prepare a CSV manifest with columns: `patient_id,image_path,label,modality` (where `label` is integer `0..3` or the matching `MODALITY_CLASS_CATALOG` code).
2. Run:
   ```bash
   python ai-service-python/imaging_pipeline/train_densenet.py \
     --manifest-csv /path/to/authorized_cxr_manifest.csv \
     --modality CXR \
     --epochs 20 \
     --batch-size 8 \
     --device auto
   ```
3. `dataset.py` performs a **strict patient-level 70% / 15% / 15% stratified split** on unique `patient_id`s and asserts `set.isdisjoint(...)` across train/val/test to prevent patient-identity leakage.
4. Images are preprocessed identically to runtime inference (`app/imaging.py` + `app/xai_engine.py`): grayscale luminance conversion, linear min-max normalization, `224×224` bilinear resize, 3-channel replication, and ImageNet standardization.
5. Artifacts are tagged `checkpoint_data_provenance = "EXTERNAL_CLINICAL_COHORT"`.

### 3.2 Mode B: Deterministic Synthetic Benchmark Verification (`--synthetic-benchmark`)
To verify the entire training, checkpoint-validation, calibration, and HiResCAM pipeline end-to-end **without** fabricating clinical accuracy or downloading gated datasets:
```bash
python ai-service-python/imaging_pipeline/train_densenet.py --synthetic-benchmark
```
- **Fixture Specification (`SYNTHETIC_BENCHMARK_FIXTURE`):**
  - Generates **240 unique synthetic patients** (`60` patients per class × `2` views per patient = **480 images** at `256×256` resized to `224×224`), aligned 1-to-1 with `MODALITY_CLASS_CATALOG["CXR"]`:
    - `0`: `CXR_NO_ACUTE_FINDING` — clear bilateral radiolucent lung fields, sharp costophrenic angles, normal cardiothoracic ratio.
    - `1`: `CXR_PARENCHYMAL_OPACITY` — randomized unilateral/multifocal focal airspace opacities across right/left and upper/mid/lower parenchymal zones.
    - `2`: `CXR_PLEURAL_EFFUSION` — dependent costophrenic angle blunting with concave lateral pleural effusion meniscus.
    - `3`: `CXR_CARDIOMEGALY_BORDERLINE` — enlarged cardiothoracic silhouette (`CTR > 0.55`) with preserved peripheral lung fields.
  - Strictly split by `patient_id` (`168` train / `36` val / `36` test patients → `336` / `72` / `72` images) with explicit `assert set(...).isdisjoint(...)` checks (`zero_patient_leakage_verified = True`).
  - Hardware-safe defaults for Windows + NVIDIA GeForce MX330 (2 GB VRAM): `num_workers=0`, `batch_size=8`, `seed=42`, Kaiming `fan_in` initialization, `AdamW`, `CosineAnnealingLR`, early stopping on validation loss, and automatic CPU fallback on CUDA OOM.

> [!CAUTION]
> Metrics obtained under `--synthetic-benchmark` validate **numerical stability, zero-leakage splitting, post-hoc calibration convergence, and HiResCAM localization mechanics**. They **do not** establish sensitivity, specificity, or clinical diagnostic performance on real human patients.

## 4. Checkpoint Format (`omnimed-checkpoint-v2`), Integrity & Fail-Safe Loading

Checkpoints exported to `ai-service-python/models/imaging/` follow the structured `omnimed-checkpoint-v2` dictionary contract:

- **Uncalibrated export (`train_densenet.py`):**
  - `densenet121_cxr_synthetic_benchmark.pt` (with `calibration: None`)
  - `val_logits.npz` (`logits`, `labels` strictly from validation split)
  - `test_logits.npz` (`logits`, `labels` strictly from held-out test split)
  - `checkpoint_manifest.json` (records exact SHA-256 digests and split provenance)
- **Calibrated export (`calibrate_densenet.py`):**
  - Fits `TemperatureScaler` and `MulticlassPlattScaler` **exclusively on `val_logits.npz`**, selects winner on validation NLL/ECE, evaluates strictly on `test_logits.npz`, and writes `densenet121_cxr_calibrated.pt` + `calibration_metrics.json`.
- **Runtime Safety in `MedicalDenseNetXaiEngine` (`app/xai_engine.py`):**
  1. Computes SHA-256 of `MODEL_WEIGHTS_PATH` and verifies against `MODEL_WEIGHTS_EXPECTED_SHA256` if set.
  2. Validates `architecture == "densenet121"`, `num_classes == 4`, `class_codes`, `strict=True` state loading, finite weights (`torch.isfinite`), and bounded finite dummy forward logits (`|logit| < 100.0`).
  3. On **any** failure (corrupted file, SHA-256 mismatch, wrong head shape, non-finite/exploding weights), safely catches the error, records `checkpoint_load_error`, and rolls back to `RESEARCH_UNVERIFIED`.
  4. Strictly distinguishes three runtime states:
     - `RESEARCH_UNVERIFIED` (default / rollback)
     - `CUSTOM_CHECKPOINT` (validated uncalibrated weights)
     - `CALIBRATED_CHECKPOINT` (validated weights + validated post-hoc calibration state, with `ece_score`, `brier_score`, `nll_score`, `reliability_bins`, `checkpoint_sha256`, and `checkpoint_data_provenance`).
